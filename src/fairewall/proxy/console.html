Kill switch

Stops agents immediately: every tool call in scope is blocked, even in shadow mode, until someone with the reviewer key releases it. Use it when an agent is misbehaving and you need it to stop now, before you know why.

Connect your agent

Three calls cover most integrations. Replace $FAIREWALL_API_KEY with your key.

  1. Before a tool runs, ask the gateway: POST /v1/inspect/tool. Run the tool only if allowed is true.
  2. After it runs, record it so budgets and rate limits advance: POST /v1/commit/tool.
  3. Before the agent reads the result, screen it: POST /v1/inspect/output, and give the agent the returned output (secrets and personal data such as emails, phone numbers, Aadhaar, PAN and card numbers already redacted).
